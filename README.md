# RyionSite

The public website for every Ryion app: product pages, how-to guides, and the
privacy policies and support pages App Store Connect requires. It is served
as one static site (GitHub Pages), with one folder per app.

```
index.html                 Ryion home: a card linking to each app
.nojekyll                  Serve files as they are (no Jekyll), for every folder
BillCompass/               Bill Compass (iPhone, iPad, Mac)
WhereaboutsCompass/        Whereabouts Compass (iPhone, iPad)
CinematicTeleprompter/     Cinematic Teleprompter (iPhone, iPad)
```

Each app folder is self-contained: its own `style.css` (the shared layout in
that app's colours), `assets/icon.png`, and any screenshots in
`assets/screens/`. Links inside a folder are relative, so the site works
at any address, whether that is `<org>.github.io/RyionSite/`, a
`<org>.github.io` repository, or a custom domain.

## Pages per app

| App | Product page | Privacy policy | Also |
| --- | --- | --- | --- |
| Bill Compass | `BillCompass/index.html` | `BillCompass/privacy.html` | features, guide, sync, FAQ, support. Generated by `BillCompass/build.py` (see its README) |
| Whereabouts Compass | `WhereaboutsCompass/index.html` (includes How to Use and FAQ) | `WhereaboutsCompass/privacy.html` | |
| Cinematic Teleprompter | `CinematicTeleprompter/index.html` (includes How to Use, Pricing and FAQ) | `CinematicTeleprompter/privacy.html` | |

The Whereabouts Compass and Cinematic Teleprompter pages are plain HTML and are
edited directly.

## Writing the copy

Every claim on these pages was checked against the app's source rather than
assumed. Menu items, buttons and settings are named exactly as the app shows
them, so a reader can find what a page points to. When an app changes what
it stores, sends or asks permission for, update its privacy page and the date
at the top of it.

## Adding an app

1. Make a folder named after the app, e.g. `NewApp/`.
2. Copy `style.css` from the closest existing app and change the colour
   variables in `:root` to the new app's palette.
3. Add `assets/icon.png` (256 px) plus `index.html` and `privacy.html`.
4. Add a card for it to the root `index.html`.

## Previewing

```
python3 -m http.server 8000
```

Then open <http://localhost:8000/>.
