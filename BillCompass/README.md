# Bill Compass — website

The public site for **Bill Compass**, a bill tracker for iPhone, iPad and Mac.
Part of RyionSite, the one site for every Ryion app; this folder is the Bill Compass
section of it. It was previously served on its own at <https://billcompass-app.github.io>.

| Page | Purpose |
| --- | --- |
| `index.html` | Product page |
| `features.html` | A tour of every screen |
| `guide.html` | How to Use — step-by-step instructions |
| `sync.html` | Lifetime iCloud Sync: buying, restoring, troubleshooting |
| `faq.html` | Frequently asked questions |
| `privacy.html` | Privacy policy — **required** by App Store Connect |
| `support.html` | Support — **required** by App Store Connect, and it must be a page rather than a `mailto:` link |

The app's own source lives in a separate, private repository. Nothing here
is generated from it at build time, so the site can be edited on its own.

## Editing

The pages are generated by `build.py` at the root of RyionSite, like every
other page on the site. The product page's copy is the `BILL` entry in
`site/content.py`; the other pages' copy is in `site/pages/BillCompass/`.
Edit there, then run `python3 build.py` from the root.

`assets/icon.png` is a 256px copy of the app icon; replace it when the app
icon changes.

`assets/screens/` holds the screenshots. They are scaled from the App Store
screenshots in `AppStore/Screenshots/` (see the root README for how those are
taken): 600px JPEGs for iPhone, 1400px for iPad and Mac.

The `.nojekyll` at the root of RyionSite tells Pages to serve the files as
they are rather than running them through Jekyll.
